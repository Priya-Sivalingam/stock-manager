# Stock Manager

Desktop stock management app for a small wholesale and retail shop.

**Stack:** C# .NET 8, WPF (MVVM), EF Core 8, SQLite, Inno Setup

## Features (v1.0)
Products, goods receipt, sales, stock adjustments, low stock report,
stock valuation and sales reports (CSV export), daily backup.

## Run
1. Install Visual Studio 2022 (.NET desktop workload)
2. Open `StockManager.sln`, set `StockManager.App` as startup project, press F5

## Docs
User manual and developer guide are in the `docs/` folder.
